# File Detail — Flow

## Open File Detail

Từ File List hoặc Search Results:

File Row
→ /files/:id
→ File Detail

## Back

Khi user bấm Back:

File Detail
→ quay lại state trước đó của /files

Nếu mở từ File List:
→ quay lại File List

Nếu mở từ Search Results:
→ quay lại Search Results và giữ:

- keyword
- filter
- search results
- scroll position
